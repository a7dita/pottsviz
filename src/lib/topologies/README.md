# Ordered structural association topologies

The design has 16 binary 49 × 49 matrices, with **frontal rows and posterior
columns**. Files retain generator order. Generation, loading, simulation and
matrix displays never relabel, shuffle or spectrally sort memory indices.

| IDs | Definition |
| --- | --- |
| `original` | 49 one-to-one pairs (identity), degree one |
| `random` | Degree-seven random regular reference, generated by 40,000 accepted degree-preserving edge swaps |
| `m0`–`m6` | Exactly m of each memory's seven partners lie in its corresponding group; the rest lie outside |
| `s1`–`s6` | Each pair of posterior memories in a group of seven shares exactly s frontal targets; cross-group pairs share at most one |
| `ms7` | Common m7 = s7 endpoint: seven complete 7 × 7 association blocks |

Groups have no assumed semantic or spatial meaning. m0 forbids within-group
edges; m1 fixes exactly one per memory, so neither replaces the unrestricted
random reference. s0 is omitted because it is isomorphic to s1. ms7 is stored
once and is accessible at the extreme of both frontend sliders.

All conditions have 49 memories per half. Every graph except original has
degree seven on both sides. original has 49 association components and ms7
has seven; the other conditions are connected. Row-normalized edge weights
are 1/k, preserving a total association weight of one per memory.

`manifest.json` and `metrics.csv` are freshly calculated from the saved CSVs:

- R4 = log(1 + N4), where N4 is the number of bipartite four-cycles;
- Q*: approximate maximum Barber bipartite modularity, normalized with each
  graph's actual degree, using deterministic component/structural starts and
  21 random starts (seed 1729). Complete-component graphs have exact values:
  original = 48/49 and ms7 = 6/7;
- gamma = 1 − sigma2(B/k)^2, the gap of a two-step association walk.

The degree-one original reference should be interpreted separately when
comparing modularity. For s1–s7, N4 = 147 choose(s, 2) and gamma = 1 − s/7.
The generator fixes the topology seed at 20261009; dynamic and memory-pattern
seeds remain independent.

Regenerate the matrices and fresh metrics from the repository root:

```bash
python3 scripts/generate_topologies.py
```

The generator requires NumPy and SciPy. `analysis/topology_design.ipynb`
reproduces the construction, verifies the fresh scores, displays all 16
matrices in saved order and compares their three metric coordinates.
