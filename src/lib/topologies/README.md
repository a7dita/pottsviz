# Ordered structural association topologies

The design has 17 binary 49 × 49 matrices, with **frontal rows and posterior
columns**. Files retain generator order. Generation, loading, simulation and
matrix displays never relabel, shuffle or spectrally sort memory indices.

| IDs | Definition |
| --- | --- |
| `original` | 49 one-to-one pairs (identity), degree one |
| `random` | Degree-seven random regular reference, generated by 40,000 accepted degree-preserving edge swaps |
| `m0`–`m6` | Exactly m of each memory's seven partners lie in its corresponding group; the rest are randomly chosen outside |
| `m7` | Seven complete 7 × 7 association blocks; the unchanged former ms7 matrix |
| `r1`–`r7` | Exactly r local ring partners per memory, with 7−r randomly chosen outside the local neighbourhood, on both sides |

Groups have no assumed semantic or spatial meaning. m0 forbids within-group
edges; m1 fixes exactly one per memory, so neither replaces the unrestricted
random reference. The shared-target family has been replaced by rings.

For frontal index f and posterior index p in 0,…,48, define:

```text
L[f,p] = 1 if (p−f) mod 49 is in {0,1,2,3,46,47,48}; 0 otherwise.
sum_p C[f,p] = sum_f C[f,p] = 7
sum_p C[f,p]*L[f,p] = r for every f
sum_f C[f,p]*L[f,p] = r for every p
```

The generator adds r disjoint random perfect matchings inside L, then 7−r
outside L, excluding already occupied edges. This is the same construction
approach used for modular graphs. Random matching choices are not a claim of
uniform sampling over all admissible graphs. r counts local connections,
not jump distance or an exact number of common targets between memory pairs.
The seven local offsets are fixed at every level. r7 equals L exactly.

All conditions have 49 memories per half. Every graph except original has
degree seven on both sides. original has 49 association components and m7
has seven; the other conditions, including r7, are connected. Row-normalized
edge weights are 1/k, preserving a total association weight of one per memory.

`manifest.json` and `metrics.csv` are freshly calculated from the saved CSVs:

- R4 = log(1 + N4), where N4 is the number of bipartite four-cycles;
- Q*: approximate maximum Barber bipartite modularity, normalized with each
  graph's actual degree, using deterministic component/structural starts and
  21 random starts (seed 1729). Complete-component graphs have exact values:
  original = 48/49 and m7 = 6/7;
- gamma = 1 − sigma2(B/k)^2, the gap of a two-step association walk.

The degree-one original reference should be interpreted separately when
comparing modularity. r7 has N4 = 1715 and gamma ≈ 0.0640810558.
The reference and modular construction seeds are unchanged. Ring r uses
20261009 + 200 + r. Dynamic and memory-pattern seeds remain independent.

Regenerate the matrices and fresh metrics from the repository root:

```bash
python3 scripts/generate_topologies.py
```

The generator requires NumPy and SciPy. `analysis/topology_design.ipynb`
reproduces the construction, verifies the fresh scores, displays all 17
matrices in saved order and compares their three metric coordinates.
